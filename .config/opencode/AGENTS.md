# Global Agent Instructions

## Working Style
- Inspect the codebase before proposing or making changes.
- Prefer small, focused edits over broad rewrites.
- Do not revert user changes unless explicitly asked.
- Run relevant verification when feasible.

## Tool Use
- Prefer fast search tools over broad shell commands.
- Use current documentation for library, framework, SDK, CLI, and cloud-service APIs.
- Keep secrets out of committed files.

## Git
- Do not commit, amend, or push unless explicitly requested.
- Before committing, inspect status and diff.
